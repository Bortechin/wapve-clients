# Security policy

Security reports are accepted for the latest published source on main.

Use this repository's **Security → Report a vulnerability** feature:
https://github.com/Bortechin/wapve-clients/security/advisories/new

Include the affected client, source revision, impact and minimal reproduction
using accounts and data you control. Do not include passwords, session tokens,
private keys or unrelated user data. If private reporting is unavailable, use
the support route at https://wapve.com/support to request a private security
contact before sending sensitive details.

Do not create a public issue containing an unpatched vulnerability. Do not
probe other users, bypass access controls or perform load/disruptive testing
against the live service. The source license is not authorization to do so.

The repository contains no backend, production credentials or official signing
keys. Browser-visible configuration and client-side checks are not secrets or
server-side authorization boundaries. Report suspected server-side issues
privately through the same support route.

No bounty or fixed response deadline is promised.
