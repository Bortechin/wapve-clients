# Contributing to Wapve Clients

Bug reports, translations, accessibility improvements, tests and focused code
changes are welcome. Read README.md and LICENSE first. This is a source-available
project with noncommercial source terms, not an OSI-approved open-source project.

1. Open an issue before a large feature or architectural change.
2. Fork the repository, create a focused branch and keep unrelated edits out.
3. Update both Turkish and English strings; preserve keys and placeholders.
4. Run the checks relevant to your changes and describe their results in the PR.
5. State any service, device or native build checks you could not perform.

Do not include credentials, real user data, signing keys or deployment files.
The API and server infrastructure are maintained separately and are not part
of this repository. A client change cannot grant additional server permissions.

## Security

Use the private reporting route in SECURITY.md. Never publish an exploit,
credential or personal data in a public issue. Reviewers will not ask you to
send production passwords or signing keys.
